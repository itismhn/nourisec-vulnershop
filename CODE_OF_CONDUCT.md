# Code of Conduct

## Our pledge

We want NouriSec VulnerShop to be a welcoming place to learn, regardless of skill
level. Plenty of people using this lab are brand new to pentesting — treat beginner
questions with the same respect as advanced ones.

## Expected behavior

- Be respectful and constructive in issues, PRs, and discussions.
- Assume good faith. Most mistakes are learning in progress, not incompetence.
- Keep discussion focused on the project — the lab, the docs, the code.

## Unacceptable behavior

- Harassment, insults, or personal attacks of any kind.
- Using this project or its community to target, attack, or embarrass real people,
  companies, or systems outside the lab itself.
- Publishing others' private information without consent.
- Any conduct that would reasonably be considered inappropriate in a professional
  setting.

## Scope

This applies to all project spaces — issues, pull requests, discussions — and to
anyone representing the project in other public spaces.

## Enforcement

Violations can be reported to **itismhn@yahoo.com**. Maintainers may remove comments,
close issues/PRs, or block contributors who violate this code of conduct.
