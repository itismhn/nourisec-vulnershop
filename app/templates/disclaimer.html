Purpose

NouriSec VulnerShop is a deliberately vulnerable e-commerce application built solely for hands-on penetration-testing education. It is used as a lab target in the paid NouriSec training course, which follows the OWASP Web Security Testing Guide (WSTG) methodology and the OWASP Top 10 (2021).

Scope of authorized testing

Authorized testing is limited to this application only, running in your own isolated lab environment (local machine, Docker container, or a private VPS behind a firewall that you control). You are not authorized to use any technique demonstrated here against any other system, service, or organization. Do not attack systems you do not own or do not have explicit written permission to test.

No real data

Every account, product, order, and message in this application is fake and seeded by a script. Never enter real personal information, real passwords, or real payment details anywhere in this app, even though the storefront is designed to look realistic.

Resetting the lab

Run python scripts/reset_db.py (or use the "Reset Database" button in the admin panel) at any time to wipe the database and restore the original seeded state, so multiple students can practice repeatedly.
