CSRF proof-of-concept

This page demonstrates the CSRF vulnerability in VulnerShop's /account/change-email endpoint (see INSTRUCTOR_GUIDE.md, finding #7). Open this file directly in a browser while logged into VulnerShop in another tab on the same browser, running at http://127.0.0.1:5000. The form below auto-submits and silently changes the logged-in victim's email address.

Training use only — target only your own local VulnerShop instance.
